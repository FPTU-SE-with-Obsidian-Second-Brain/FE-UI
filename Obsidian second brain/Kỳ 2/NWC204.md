<tr><td><b>Description:</b></td><td>This course is based on the first course in the CCNA curriculum. It introduces the network architectures, models, protocols, and components that enable communication among users, devices, applications, and data across modern computer networks and the Internet. Key topics include Ethernet fundamentals, IP addressing, basic network operations, and introductory network security. By the end of the course, students will be able to build and configure simple local area networks (LANs), develop appropriate IP addressing schemes, apply basic security measures, configure routers and switches, verify network connectivity, and troubleshoot common network problems.<br>The course includes an individual Practical Examination (PE) that assesses each student’s ability to apply these skills independently. During the examination, students are required to design or complete a small network, calculate and configure IP addresses, perform basic router and switch configurations, secure network devices, verify connectivity, and identify and correct common configuration errors.<br>The course is organized into a series of modules, each of which represents an integrated unit of learning. Every module includes instructional content, practical activities, and assessments aligned with a defined set of competencies. The scope and duration of each module vary according to the level of knowledge and practical skill required. Some modules provide foundational knowledge that supports later learning and prepares students for concepts covered in the CCNA certification examination, even where the foundational content is not assessed directly.</td></tr>
